### 正文

```
做家教一年，最烦的不是上课，是备课。

一节课要先想题型、再排练习、再算答案、再排版、再转 Word，
两个学生一周四节课，光是备课就吃掉我两个晚上。

后来我把它拆成了一条流水线，现在：
说清这节课讲什么 → 10 分钟 → 三份能直接打印的 docx。

关键是这三份东西的分工，我踩了一年的坑才定下来：

📄 学案（给学生）
只放题干 + 空白解题区。写提示？学生会照着套，不动脑。

📄 教案（给自己）
只放答案 + 解析。
我第一版教案写了课前提要、学情分析、时间分配……打印一次十几页，收费按页算，直接劝退。
现在整份 ≤200 行，上课翻两下就找到答案。

📄 课后作业（给学生）
独立一份，末尾不放答案。下次课我对着教案报答案。

还有几个反人类的坑，我一并写进文档了：
· 模型会把答案抄进学生版学案（一次返工17处）
· 打印出来的纸没有文件夹，一叠纸分不清是谁的（文件名必须带学生+科目+章节）
· 公式转 Word 会静默变成纯文本，肉眼看不出来（用数字验收）

我把整套东西开源了，包括：
✅ 完整提示词（直接复制能用）
✅ 一套物理《自由落体运动》的完整范本三件套
✅ 4 个脚本：建目录 / 转docx+自检 / 收课清理 / 体检
✅ 我这一年踩过的坑，全写在"踩坑迭代史"里

不需要 API，不需要服务器，不需要训练模型。
你会说清"这节课讲什么"就行。

评论区扣「备课」我发路径 👇
（数学、化学的范本还没做，有人一起补吗）
```

## 二、即刻（主阵地：独立开发者 / AI 从业者）

```
开源了一个很小的东西，但解决了我一整年的痛。

背景：做一对一兼职家教，冲突在于——要备好课（结构、题型、答案、排版），
又要控制时间。用 ChatGPT 出稿很容易，但要它出"能直接打印给学生"的三份文档，
每次都要重新调格式，而且它总把答案抄进学生版。

所以我把"结构性的事"从模型手里拿走了：

· 建目录、命名、转docx、数公式 —— 交给 4 个 PowerShell 脚本 + pandoc
· 判题型、拟题、写解析 —— 交给模型
· 验算答案 —— 留给自己（数学物理不能交给模型）

一个反直觉的结论：
让 AI 干活，"结构"必须由代码保证，"内容"才交给模型。
我试过让模型自己组织结构，三次输出三种栏目顺序。

另一个反直觉的：教案越"完整"越没用。
第一版教案带课前提要/学情/时间分配/评分点，打印十几页，上课根本不翻。
现在只留答案+解析，≤200行。打印成本减半，找答案快十倍。

不需要 API、不需要服务器、不需要微调。就是一个能跑的 LLM + pandoc。

已开源（MIT），代码量很小（4 个脚本 ~300 行），主要资产是提示词和范本。
```

# 复现教程（保姆级 · 从零到第一份可打印 docx）

> 目标：**不依赖任何经验，照着敲完，得到三份能直接打印的 docx。**
> 全程约 40 分钟，其中 30 分钟是等模型出稿。

---

## 0. 你最终会得到什么（先看终点）

```
D:\家教\家教k01\物理\自由落体运动\
├── 学案.md
├── 教案.md
├── 课后作业.md
├── figs\                                    （空着也行）
├── 家教k01物理_自由落体运动_学案.docx        ← 打印给学生
├── 家教k01物理_自由落体运动_教案.docx        ← 打印给自己
└── 家教k01物理_自由落体运动_课后作业.docx    ← 打印给学生
```

---

## 1. 环境（5 分钟）

### 1.1 装 pandoc

```powershell
pandoc --version
```

没装的话：

```powershell
winget install --id JohnMacFarlane.Pandoc
```

装完**重开一个终端**（PATH 需要刷新），再验一次 `pandoc --version`，看到版本号即可。

### 1.2 确认 PowerShell 版本

```powershell
$PSVersionTable.PSVersion
```

`5.1.x` 或更高都行。**不要用 PowerShell 7 的 pwsh 跑**——脚本用了 5.1 的行为（BOM 解析），7 下也能跑但报错信息不同，排查会绕远。

### 1.3 允许执行本地脚本

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

只对当前窗口生效，关掉就恢复，安全。

---

## 2. 建目录（2 分钟）

### 2.1 建学生目录 + 两个固定文件

每个学生在根目录下必须有两个文件：

- `备课主档.md` —— 这个学生的整体情况与教学计划
- `学生已知数据.md` —— 已知/未知/错误习惯/清理记录

```powershell
$root = 'D:\家教'
New-Item -ItemType Directory -Force -Path "$root\家教k01" | Out-Null
Copy-Item .\templates\备课主档.template.md     "$root\家教k01\备课主档.md"
Copy-Item .\templates\学生已知数据.template.md "$root\家教k01\学生已知数据.md"
```

然后打开这两个文件，把 `[占位符]` 换成真实信息。**别跳过这步**——后面模型要读它们来判断学生水平。

### 2.2 建章节骨架

```powershell
.\scripts\new-lesson.ps1 -Student 家教k01 -Subject 物理 -Chapter 自由落体运动 -Root $root
```

看到两行 `OK:` 就成功了。脚本会拒绝覆盖已存在的章节（防止手滑毁掉上次的稿），要补漏的目录加 `-Force`。

---

## 3. 出三份 md（30 分钟，主要是等）

### 3.1 贴提示词

把 `docs/SKILL-原版提示词.md` 的全文贴进对话（这是项目的核心资产，别删减）。然后补任务指令：

```
【任务】
这节课：《自由落体运动》，学生高一，基础中等。
知识点：自由落体定义、v=gt、h=½gt²、v²=2gh、g=10m/s²、竖直上抛。
课时：一节（45 分钟）。

【输出】
三份独立文件，分别用 ```markdown 代码块包裹，块前标明文件名：
学案.md / 教案.md / 课后作业.md
```

### 3.2 存文件

把三个代码块的内容分别存为章节目录下的 `学案.md`、`教案.md`、`课后作业.md`。

⚠️ **文件名必须一字不差**，脚本按固定名字查找。

### 3.3 先人工过一遍（这一步省不掉）

- 打开 `教案.md`，**自己算一遍答案**。模型算错是常态，答案错了比没答案更糟。
- 检查 `学案.md` 里有没有出现 `答案：`。有就删——答案不能给学生。
- 检查 `课后作业.md` 末尾有没有答案。有就删。

---

## 4. 转 docx 并自检（3 分钟）

```powershell
.\scripts\build-lesson.ps1 -ChapterDir "$root\家教k01\物理\自由落体运动"
```

### 期望输出

```
CHAPTER: 自由落体运动
PREFIX : 家教k01物理

Kit      Status Detail
---      ------ ------
学案     PASS   oMath=41 media=0 mdImg=0 mdMath=41
教案     PASS   oMath=58 media=0 mdImg=0 mdMath=58
课后作业 PASS   oMath=12 media=0 mdImg=0 mdMath=12

RESULT: all PASS
```

**为什么自检看这三个数**：

| 指标 | 含义 | 不正常的样子 |
|---|---|---|
| `oMath` | docx 里真正的 Word 公式对象数量 | `mdMath>0` 但 `oMath=0` → 公式全变成纯文本了 |
| `media` | docx 内嵌图片数 | `< mdImg` → 图被吞了 |
| `PLACEHOLDER` | 残留的 TODO 数 | >0 → 文档没写完就交了 |

### 报错了怎么查

| 现象 | 原因 | 修法 |
|---|---|---|
| `FATAL: pandoc not found in PATH` | pandoc 没装或没重开终端 | 重开终端 |
| `FATAL: dir not found` | 路径写错 | 用 Tab 补全，别手打中文路径 |
| `FORMULA_LOST` | 公式没包 `$...$` | 打开 md 检查，公式必须 `$v = gt$` |
| `IMAGES_LOST` | 图片路径不对 | md 里写 `![](figs/x.png)`，图放 `figs\` |
| 全 PASS 但打印出来是乱码 | 用了 pwsh 7 或文件编码不对 | 重新用 `build-lesson.ps1` 生成 |

---

## 5. 打印前最后一眼（1 分钟）

打开三个 docx：

- 学案：解题区应当是**空白**的（这是刻意的，学生自己动笔）
- 教案：应当只有「题号 + 答案 + 解析」，没有课前提要/时间分配
- 课后作业：末尾**没有答案**

篇幅参考：教案 ≤ 200 行。超了说明混进了旁白，删。

---

## 6. 上完课（1 分钟）

```powershell
.\scripts\close-lesson.ps1 -ChapterDir "$root\家教k01\物理\自由落体运动" -DryRun   # 预览要删什么
.\scripts\close-lesson.ps1 -ChapterDir "$root\家教k01\物理\自由落体运动"           # 执行
```

文件夹保留（进度记录），文件清空（省空间），自动写进 `学生已知数据.md` 的「清理记录」。

---

## 7. 第 10 章之后你会需要这个

```powershell
.\scripts\lesson-health.ps1 -Root $root
```

报告哪些章节三件套不齐、哪些是空壳。**每两周跑一次**，比翻文件夹快。

## 常见卡点速查

| 症状 | 位置 |
|---|---|
| 模型输出的结构跟范本不一样 | 喂 `examples/` 里的范本给它，或直接把结构写进指令 |
| 答案又被抄进学案 | 指令里答案单独成节，写「以下内容只写入教案」 |
| 公式在 docx 里是普通文字 | md 里必须是 `$...$`，不能是 `½gt²` 这种 |
| 图片不显示 | `--resource-path`（`build-lesson.ps1` 已自动加） |
| 中文乱码 | 文件存 UTF-8；`.ps1` 必须带 BOM |

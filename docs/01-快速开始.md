# 快速开始（5 分钟出第一份 docx）

## 前置条件

| 依赖 | 检查命令 | 说明 |
|---|---|---|
| Windows PowerShell 5.1+ | `$PSVersionTable.PSVersion` | 脚本为 5.1 编写 |
| pandoc | `pandoc --version` | ≥ 2.19 即可 |
| 一个可用的 LLM | — | 无需 API，网页版也行 |

没有 pandoc：`winget install --id JohnMacFarlane.Pandoc` 或去 pandoc.org 下载安装包。

---

## 第 1 步：放置仓库

```powershell
cd D:\
git clone <你的仓库地址> AI-Tutor-Workflow
cd AI-Tutor-Workflow
```

不需要 `npm install`，没有依赖。

---

## 第 2 步：建第一个学生目录

仓库自带脚本要求一个「根目录」，下面按 `学生/科目/章节` 三层组织。

**学生文件夹叫什么都行**（`小明`、`studentA`、`studentA` 都可以），脚本只认三层结构，不挑名字。下文用 `家教k01` 举例，你换成自己的学生名即可。

```powershell
# 先建学生根目录与两个固定文件（见 templates/）
mkdir D:\家教\家教k01
copy .\templates\备课主档.template.md      D:\家教\家教k01\备课主档.md
copy .\templates\学生已知数据.template.md  D:\家教\家教k01\学生已知数据.md
```

然后建章节：

```powershell
.\scripts\new-lesson.ps1 -Student 家教k01 -Subject 物理 -Chapter 自由落体运动 -Root D:\家教
```

输出：

```
OK: D:\家教\家教k01\物理\自由落体运动
OK: D:\家教\家教k01\物理\自由落体运动\figs

NEXT:
  1. create 3 sources in the chapter dir: 学案.md / 教案.md / 课后作业.md
  2. put images in figs\ and reference them relatively (![](figs/x.png))
  3. build: build-lesson.ps1 -ChapterDir "..."
```

---

## 第 3 步：让模型写三份 md

打开 `docs/SKILL-原版提示词.md`，把全文贴进对话，再补一句：

```
这节课讲《自由落体运动》，学生是高一。
知识点：自由落体定义、v=gt、h=½gt²、v²=2gh、重力加速度、竖直上抛。
请按上面的规则输出三份文件，分别用 ``` 代码块包裹：
学案.md / 教案.md / 课后作业.md
```

把返回内容分别存进章节目录。**结构不要求你记，照 `examples/` 里的范本对齐即可。**

⚠️ 三份 md 的取名必须精确：`学案.md`、`教案.md`、`课后作业.md`（脚本按这三个名字找）。

---

## 第 4 步：转 docx + 自检

```powershell
.\scripts\build-lesson.ps1 -ChapterDir "D:\家教\家教k01\物理\自由落体运动"
```

期望看到 `RESULT: all PASS`。若出现 `WARN`：

| WARN | 含义 | 处理 |
|---|---|---|
| `IMAGES_LOST` | 图片没进 docx | 检查 md 里是否写 `![](figs/xxx.png)`，且图确实在 `figs\` |
| `FORMULA_LOST` | 公式没转成 Word 公式对象 | 公式要写成 `$...$`，不能用纯文本 |
| `PLACEHOLDER=n` | 还有 TODO / 待补充 | 打开 md 搜这几个词 |

---

## 第 5 步：上完课收尾

```powershell
.\scripts\close-lesson.ps1 -ChapterDir "D:\家教\家教k01\物理\自由落体运动" -DryRun   # 先预览
.\scripts\close-lesson.ps1 -ChapterDir "D:\家教\家教k01\物理\自由落体运动"           # 真删
```

**保留文件夹**（作为进度记录），清空里面的文件，并自动登记到 `学生已知数据.md` 的清理记录。

---

## 随时体检

```powershell
.\scripts\lesson-health.ps1 -Root D:\家教
```

只读，报告：结构是否合规、哪些章节三件套不齐、哪些章节是空的。

---

## 换成你自己的学科

脚本完全学科无关。要改的只有：

1. `docs/SKILL-原版提示词.md` 里的「题型」组织方式（物理按题型，数学按考点，英语按题型+语法点）。
2. `examples/` 里的范本换成你学科的（**这一步最重要，模型是照着范本抄结构的**）。
3. `templates/paper-reference.docx` 换成你想要的字体（默认宋体 12pt / 1.5 倍行距）。

# 家教备课助手

## 描述
用户是家教老师。当用户提供一节课的知识点/课程内容时，按本技能输出**学案 + 教案 + 课后作业**三件套
（三个独立文件）。答案分发规则：

- **学案** → 学生；末尾答案速查只含课堂练习 + 拓展（供自批），不含课后作业答案
- **教案** → 教师自己用；必须包含学案全部题目 + 课后作业全部题目的答案与解析
- **课后作业** → 学生；独立文档、不附答案，由教师下次课对答案提供

## 强制第一步：读范本

写任何新课程资料之前，**必须先完整读取本目录下的全部范本文件**（学案、教案、课后作业）：

- `范本_自由落体运动_学案.md` —— 学案结构范本
- `范本_自由落体运动_教案.md` —— 教案结构范本（含学案 + 作业全部答案）
- `范本_自由落体运动_课后作业.md` —— 课后作业结构范本（不带答案）

新资料的**结构、栏目顺序、详略程度、口诀风格、表格用法**全部向范本对齐。
范本缺失时，按下文「结构模板」执行。

## 学案结构模板（学生用）

```
# 《课题名》学案
姓名/日期栏

## 第一部分：N大题型标准解题流程（做题前先看这里）
### 底层通法（所有题型共用）—— 最少的必要前提 + 基本公式速览表
### 题型① ~ 题型N（每个题型固定五件套）：
  - 题目标志表（考试怎么问）
  - 核心公式
  - 标准步骤（表格或编号步骤）
  - 易错提醒
  - 一句话操作（口诀）

## 第二部分：课堂练习（每题标注【题型N】）
含解题区（**解题区只留空白，不写提示/点拨**）；（高考真题标注年份·省份）

## 第三部分：拓展视野（跨情境/陷阱题/铺垫题）

## 第四部分：本节总结
题型自查清单（□）+ 一句话总结 + 指向课后作业（作业独立成文）

## 附录：答案速查（学生自批用，只含课堂练习+拓展，不含课后作业）
```

## 教案结构模板（教师版 · 打印精简版）

**定位：** 教案只写**答案 + 解析**两样。用户 2026-10-30 规则：打印按页收费，
**除了答案解析什么都不要放** —— 课前提要、学情判断、本课目标、重难点、时间分配、课堂追问清单、
收尾自查、评分点表格、易错提醒、批改关注、题目复述，一律不写。
**答案范围：** 教案必须包含学案全部题目 + 课后作业全部题目的答案与解析（备课时一次算全）。

```
# 家教{编号}{科目} · {章节} · 教案

**例题 1-1　题目标题**

答案：…（数值与结论，照抄，不省略）
解析：1. … 2. …

**变式 1-2　题目标题**

答案：…
解析：1. …

…（题型二~四同格式）

**作业 1**

答案：…
解析：1. …
…（作业 2~5 同格式）
```

- 公式一律行内 `$...$`，**不用 `$$` 独立公式块**（省纸）。
- 目标篇幅 **≤ 200 行**；超过 200 行说明混进了旁白，回头删。

## 课后作业结构模板（学生用）

**定位：** 独立文件、不发答案。题目从学案题型里出（可重做学案原题）、每题型 1~2 道，
多余的练习量放这里。

```
# 《课题名》课后作业
姓名/日期栏 + 使用说明（先翻学案认题型；做不出的标"？"）

## A组（必做）—— 按题型各1道 / 重做学案原题
## B组（选做）—— 混合/拔高 2~4 道

（文档末尾不放答案；答案在教案「作业答案」节，下次课对答案提供）
```

## 课型 B：错题精讲（考前一天 / 一节复习课）

适用：用户说「讲解错题」「考前把错题过一遍」，并给出整份作业或试卷（照片/文件）。

1. **先逐题确认题面**：从照片识题必须核对题干数字、选项、图形；图不清或被学生涂改遮挡的题，
   标「见原卷」或经用户同意后略去，**不许猜**。
2. **按知识板块归并**：把错题重排进 5~6 个板块（如「一元二次方程概念与判别式」「相似模型」「几何变换与最值」）；
   学案里每题保留 题源编号 + 完整题干 + 解题区（**只留空白，不写提示**）。
3. **答案独立验算**：数值题、几何题建系、面积题用网格采样，能编程验算的一律脚本验算，**不许只靠口算**；
   每题必写「易错提醒」与「批改关注」（学生可能错在哪一步）。
4. **教案首页给一张「错题速查表」**：题号 | 考点 | 正确答案 | 错因关键词——这是本课型的核心产出。
5. 课后作业＝同题型变式（换数据/换情境），题干里可写「答案可能不止一个」等要求，**不给解题提示**。

## 工具链备忘（本机实测）

- **图形**：本机**没有 matplotlib**；几何图用 Pillow 手绘（坐标变换 + 直角符号 + 中文字体
  `C:/Windows/Fonts/msyh.ttc`），导出 PNG 后在 md 里用 `![](...){width=..%}` 引用。图必须在转 docx 前画好。
- **pandoc 图片路径坑**：pandoc 以**当前工作目录**解析相对图片路径，**不是 md 所在目录**。
  跨目录调用必须加 `--resource-path=<md所在目录>`，否则图片会静默变成文字占位（2026-10-06 已踩）。
- **交付前自检 docx**：解压读 `word/document.xml`，核对 `<m:oMath` 段数≈公式数、`word/media/` 张数＝图片数。
- **docx 可回源成 md**：`pandoc x.docx -t markdown --wrap=none --extract-media=媒体目录 -o x.md`；
  图片按「在文档中出现的顺序 + 逐张尺寸校验」还原文件名（顺序错会张冠李戴）。
  `\dfrac→\frac`、`\triangle→\bigtriangleup` 属正常规范化，不算丢内容。
- **中文路径**：Python 脚本里写含中文的绝对路径会偶发乱码（表现为 `FileNotFoundError`）。
  ⇒ 脚本写成 `.py` 文件再执行（别用管道喂 stdin），工作目录/中转目录用纯 ASCII，pwsh 用 `workdir` 参数。

## 硬性规则

1. **联动原则：** 学案的题型结构/编号/练习量一旦确定或变更，教案必须同步重写；
   交付前交叉核对两份文档的题型编号、例题对应关系、答案完全一致。
2. **内容闭环：** 教案中每个题型、每道题必须有答案与解析，当堂闭环；
   严禁出现"下节课再讲""后续课程揭晓"式悬念（除非用户明确要求分次课）。
3. **内容来源：** 题目和知识点 100% 来自用户提供的材料；用户没给的题不自己编造。
   用户只给知识点不给题时，向用户确认是否需要代拟例题后再动笔。
4. **排版细则：**
   - 含物理量符号的表达式一律 `$...$` 包裹转 Word 公式对象；
     纯叙述中的纯数值（如"从500m高空"）保留正文
   - 单位格式：`$g = 10\,\mathrm{m/s^2}$`；中文下标可用 `\text{}`（如 `$t_{\text{上}}$`）
   - 标题层级 `#` → `##` → `###` 不跳级；模块间 `---` 分隔；无 emoji
5. **生成流程：** 先写 `.md` → `pandoc 文件.md -o 文件.docx`
   （pandoc 路径 `pandoc`）→
   把 docx 转回 markdown 抽查公式还原，验证 OMML 转换成功。
6. **覆盖已有文件前**询问是否备份到 `.\backup`。
7. **简洁优先（2026-10-06 用户规则）：** 范本是给人和 OpenCode 看的**执行模板，照抄即成品**。
   除题目、答案、解析、提醒外，**不写多余的话**——时间分配、课时安排、环节用时、心理鸡汤、重复说明、
   示例性废话，一律不写。**学案与课后作业的解题区只留空白，不写任何提示。**
8. **答案分发：** 学案附录只含课堂练习+拓展答案（自批用）；课后作业文档内不放答案，
   答案统一在教案中，由教师下次课对答案提供。交付前核对：教案答案与学案、课后作业逐题一致。
9. **派活规格铁律（2026-10-10 固化，把三件套交给 OpenCode / 子代理出稿时必守）：**
   - **学案正文只允许出现「题干 + （解题区）」**；答案**一律不得**写在题目下方，
     答案只出现在学案附录的答案速查表里。
   - 规格里给答案时**单独成节**并注明「以下答案只写入教案」，别写成题目旁边的「答案：…」
     ——否则会被原样抄进学案（2026-10-10 数学 8 处、物理 9 处返工）。
   - 规格里**不必要求它通读三个范本**：结构与栏目直接写进规格即可（省 30–60 s，也少一个抄错源）。
   - 图片只给一行「原样插入 `![](figs/xxx.png){width=45%}`」，不要写「图片引用（放在题干后面）：」
     这类说明句（会被照抄进成品）。
   - 交付前机械验证：学案里 grep 不到 `答案：`、标题风格与范本一致、docx 自检通过后才算完工。
10. **教案只留答案+解析（2026-10-30 用户规则，优先级最高）：** 見「教案结构模板（打印精简版）」。
    验收：教案里 grep 不到「课前提要 / 学情 / 时间分配 / 追问 / 收尾 / 评分点 / 提醒 / 批改关注 / 分钟」，
    且 `$$` 计数为 0、行数 ≤ 200。改写已有教案时，**先备份原 md 再覆盖**（原稿可能是唯一来源）。
11. **docx 命名规则（2026-10-30 用户规则）：** 打印出来的纸没有文件夹，文件名必须自带身份 ——
    `<学生><科目>_<章节>_<学案|教案|课后作业>.docx`，例：`studentA物理_已学大题专题_教案.docx`。
    md 源文件保持短名（`学案.md` / `教案.md` / `课后作业.md`）。
    `build-lesson.ps1` 已按此规则生成（自动从「学生/科目/章节」三层目录推前缀）；
    `lesson-health.ps1` 按 docx 判定三件套是否齐全，md 缺失只记一条附注。

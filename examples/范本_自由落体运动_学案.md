## 第一部分：六大题型标准解题流程（学案核心·做题前先看这里）

> **使用说明：** 这一页是整本学案的"操作手册"。做任何题之前，先翻到这一页，找到对应的题型编号，按标准步骤代入即可。**六个题型全部配齐，没有留悬念。**

### 底层通法（所有题型共用）

自由落体 = 匀变速直线运动的特例（$v_0 = 0$，$a = g$）。每道题动笔前先确认这两个条件是否满足。

三个基本公式（全部题型共用）：

| 公式 | 用途 |
|:---:|:---|
| $v = gt$ | 已知时间求速度 |
| $h = \dfrac{1}{2}gt^2$ | 已知时间求高度 |
| $v^2 = 2gh$ | 不知时间时，直接联系 $v$ 与 $h$ |

### 题型① 普通落体（知一求一）

| **题目标志** | 直接告诉下落时间 $t$、或下落高度 $h$、或落地速度 $v$，求另一个 |
|:---|:---|

**核心公式：** $v = gt$，$h = \dfrac{1}{2}gt^2$，$v^2 = 2gh$

**标准步骤：**

| 题目给了什么 | 用什么公式 | 求什么 |
|:---:|:---:|:---:|
| 下落时间 $t$ | $h = \dfrac{1}{2}gt^2$ | 下落高度 |
| 下落时间 $t$ | $v = gt$ | 落地速度 |
| 下落高度 $h$ | $t = \sqrt{\dfrac{2h}{g}}$ | 下落时间 |
| 下落高度 $h$ | $v = \sqrt{2gh}$ | 落地速度 |
| 落地速度 $v$ | $t = \dfrac{v}{g}$ | 下落时间 |
| 落地速度 $v$ | $h = \dfrac{v^2}{2g}$ | 下落高度 |

**一句话操作：** 看题目给谁、缺谁，从表里挑公式直接代。

---

### 题型② 最后n秒位移

| **题目标志** | "最后1s内下落了____m"、"最后2s内的位移是____" |
|:---|:---|

**核心公式：** $\Delta h = \dfrac{1}{2}g\left[T^2 - (T-n)^2\right]$

**标准步骤：**

```
第1步：设总时间为 T（未知数）
第2步：总位移 H = ½gT²
第3步：前(T−n)秒位移 H₁ = ½g(T−n)²
第4步：最后n秒位移 Δh = H − H₁ = ½g[T² − (T−n)²]
第5步：代入题目给的数值，解出 T
第6步：代回 H = ½gT² 求总高度
```

**易错提醒：** $\dfrac{1}{2}$ 别丢！$(T-n)^2$ 展开别算错！

**例：** 最后1s下落45m → $\dfrac{1}{2} \times 10 \times [T^2-(T-1)^2] = 45$ → $5(2T-1)=45$ → $T=5\,\mathrm{s}$ → $H=125\,\mathrm{m}$

---

### 题型③ 竖直上抛（对称性）

| **题目标志** | "竖直向上抛出"、"以 $v_0$ 上抛"、"上升到最高点" |
|:---|:---|

**核心公式：** $H = \dfrac{v_0^2}{2g}$，$T = \dfrac{2v_0}{g}$

**标准步骤：**

**求最大高度 $H$：**

> 最高点速度 $v=0$ → 用 $v^2 = 2gH$ → $H = \dfrac{v_0^2}{2g}$

**求全程时间 $T$（抛出到落回抛出点）：**

> 从最高点落回 = 自由落体 → $t_{\text{下}} = \sqrt{\dfrac{2H}{g}} = \dfrac{v_0}{g}$ → $T = \dfrac{2v_0}{g}$

**求某一时刻速度：**

> 上升段：$v = v_0 - gt$（方向向上为正）
> 下落段：$v = gt$（方向向下为正，从最高点开始算）

**核心对称性（必背）：**

- 同一高度：上升速度大小 = 下落速度大小
- 同一高度：上升时间 = 下落时间

---

### 题型④ 平抛·竖直分运动

| **题目标志** | "水平抛出"、"平抛"、"飞行时间"、"水平距离" |
|:---|:---|

**核心理解：** 平抛 = 水平（匀速）+ 竖直（自由落体），两个方向互不影响

**标准步骤：**

**求飞行时间 $t$：**

> 只看竖直方向 → 从高度 $h$ 处自由下落 → $t = \sqrt{\dfrac{2h}{g}}$（**跟水平速度无关！**）

**求水平射程 $x$：**

> 先用 $h = \dfrac{1}{2}gt^2$ 求 $t$，再用 $x = v_0 t$

**一句话操作：** 求时间只看高度，求水平距离再用速度乘时间。

---

### 题型⑤ 斜抛·竖直分运动

| **题目标志** | "斜向上抛出"、"与水平面成 $\theta$ 角"、"最高点"、"射程" |
|:---|:---|

**核心理解：** 斜抛 = 竖直（竖直上抛）+ 水平（匀速），先分解再合成

**标准步骤：**

**第1步（分解初速度）：**

- 水平分量：$v_{0x} = v_0\cos\theta$（全程不变）
- 竖直分量：$v_{0y} = v_0\sin\theta$（只决定上升和下落）

**第2步（算竖直方向——竖直上抛）：**

- 上升时间：$t_{\text{上}} = \dfrac{v_{0y}}{g}$（最高点速度为零）
- 总飞行时间：$T = \dfrac{2v_{0y}}{g}$
- 最大高度：$H = \dfrac{v_{0y}^2}{2g}$

**第3步（算水平方向——匀速）：**

- 水平射程：$x = v_{0x}T = (v_0\cos\theta) \cdot \dfrac{2v_0\sin\theta}{g} = \dfrac{v_0^2\sin 2\theta}{g}$

**一句话操作：** 先分解速度 → 竖直算时间 → 水平算距离。

### 题型⑥ 图像题（v-t / a-t）

| **题目标志** | "下列v-t图像正确的是"、"根据图像判断运动状态" |
|:---|:---|

**核心规则：** 斜率 = 加速度 $a$，截距 = 初速度 $v_0$，面积 = 位移

**标准步骤（三步看）：**

```
第1步 看斜率 → 斜率 = 加速度 a
  · 斜率恒定 → 匀变速（自由落体/竖直上抛全程都是！）
  · 斜率为正 → a 为正方向
  · 斜率为负 → a 为负方向

第2步 看截距 → 截距 = 初速度 v₀
  · 正截距 → 初速度向上/正方向
  · 负截距 → 初速度向下/负方向
  · 截距为零 → 从静止释放

第3步 看与t轴交点 → 速度为零（最高点/瞬时静止）
  · 穿过t轴 → 速度方向改变（如竖直上抛过最高点）
  · 不穿过 → 一直朝一个方向运动
```

**自由落体的v-t图：** 从原点出发，斜率恒为正（向下为正）的直线

**竖直上抛的v-t图：** 从正截距出发，斜率恒为负，穿过t轴变为负

**两大易错：**

- 最高点速度 $= 0$，但**加速度 $\neq 0$**（仍为 $g$）
- 速度方向变了，但**加速度方向不变**（始终向下）

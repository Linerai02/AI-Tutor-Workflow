**练习1**

答案：$t = 0.5\ \mathrm{s}$。

解析：$h = \dfrac{1}{2}gt^2$，$1.25 = 5t^2$，$t^2 = 0.25$，$t = 0.5\ \mathrm{s}$。

**练习2**

答案：$v = 20\ \mathrm{m/s}$，$h = 20\ \mathrm{m}$。

解析：$v = gt = 10\times2 = 20\ \mathrm{m/s}$；$h = \dfrac{1}{2}gt^2 = \dfrac{1}{2}\times10\times4 = 20\ \mathrm{m}$。

**练习3**

答案：A。

解析：自由落体与质量无关，两石块第 1 s 末速度均为 $v = gt = 10\ \mathrm{m/s}$，故 $v_1 = v_2$。

**练习4**

答案：$H = 125\ \mathrm{m}$。

解析：设总时间 $T$；总位移 $H = \dfrac{1}{2}gT^2$，前 $(T-1)$ s 位移 $H_1 = \dfrac{1}{2}g(T-1)^2$；
$45 = H - H_1 = 5\left[T^2-(T-1)^2\right] = 5(2T-1)$，得 $T = 5\ \mathrm{s}$，$H = 125\ \mathrm{m}$。
检验：前 4 s 下落 80 m，最后 1 s 下落 $125-80 = 45\ \mathrm{m}$。

**练习5**

答案：B。

解析：总时间 $t_{\text{总}} = \sqrt{\dfrac{2\times10}{10}} = \sqrt{2}\approx1.4\ \mathrm{s}$；
前 5 m 时间 $t_1 = \sqrt{\dfrac{2\times5}{10}} = 1\ \mathrm{s}$；姿态调整时间 $1.4-1 = 0.4\ \mathrm{s}$。

**练习6**

答案：B。

解析：全程只受重力，$a$ 恒为 $-g$，图像是直线；取竖直向上为正，初速度为正、加速度为负，
故为正截距、负斜率，过最高点后穿过 $t$ 轴。

**练习7**

答案：（1）自由落体；（2）$t = 10\ \mathrm{s}$；（3）不会。

解析：竖直方向 $v_0 = 0$ 且只受重力，是自由落体；$500 = \dfrac{1}{2}\times10\times t^2$，$t = 10\ \mathrm{s}$；
落地时间只由高度决定，与水平速度无关。

**拓展题1**

答案：C。

解析：月球无大气，无空气阻力；羽毛与铁锤都只受重力、初速度均为 0，加速度相同，同时落地。

**拓展题2**

答案：$g_{\text{星}} = 3.6\ \mathrm{m/s^2}$。

解析：$h = \dfrac{1}{2}g_{\text{星}}t^2$，$1.8 = \dfrac{1}{2}g_{\text{星}}\times1$，得 $g_{\text{星}} = 3.6\ \mathrm{m/s^2}$。

**拓展题3**

答案：$\dfrac{4}{9}\approx0.44$。

解析：$g = \dfrac{GM}{R^2}$，$\dfrac{g_{\text{火}}}{g_{\text{地}}} = \dfrac{1}{9}\times2^2 = \dfrac{4}{9}$。

**拓展题4**

答案：A。

解析：体重 $= mg$，质量不变而体重变为 $n$ 倍，说明 $g$ 变为 $n$ 倍；
第一宇宙速度 $v = \sqrt{gR}$，应变为 $\sqrt{n}$ 倍（C 错）；第二宇宙速度由该星球决定，不再等于 $11.2\ \mathrm{km/s}$（D 错）。

**拓展题5**

答案：$H = \dfrac{v_0^2}{2g}$，$T = \dfrac{2v_0}{g}$。

解析：最高点 $v = 0$，由 $v^2 = 2gH$ 得 $H = \dfrac{v_0^2}{2g}$；从最高点落回是自由落体，
$t_{\text{下}} = \dfrac{v_0}{g}$，由对称性 $T = 2t_{\text{下}} = \dfrac{2v_0}{g}$。

**拓展题6**

答案：$H = 12.8\ \mathrm{m}$，$T = 3.2\ \mathrm{s}$，$x = 38.4\ \mathrm{m}$。

解析：$v_{0x} = 20\cos53^{\circ} = 12\ \mathrm{m/s}$，$v_{0y} = 20\sin53^{\circ} = 16\ \mathrm{m/s}$；
竖直方向 $t_{\text{上}} = \dfrac{16}{10} = 1.6\ \mathrm{s}$，$T = 3.2\ \mathrm{s}$，$H = \dfrac{16^2}{2\times10} = 12.8\ \mathrm{m}$；
水平方向 $x = v_{0x}T = 12\times3.2 = 38.4\ \mathrm{m}$。
